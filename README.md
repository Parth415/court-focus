# Court Focus

Structured tennis drills for a **Slinger ball machine** (60-ball hopper), aimed at **3.5** players who can train **45–60 minutes**, **2–3× per week**.

## Features

- Drill library by focus: forehand, backhand, serve, volleys, drop shots, game play
- How-to-play tips for every drill
- Full sessions of **~200–250 balls** (refill the hopper 3–4 times)
- Weekly plan for 2 or 3 machine days (not every day)
- Built around finishing points / coming to the net (anti-grind)
- Installable as a **PWA** on your phone home screen

## Use it

Open the live site (GitHub Pages) on your phone, then:

- **iPhone:** Safari → Share → Add to Home Screen  
- **Android:** Chrome → menu → Install app / Add to Home screen  

## Local development

```bash
cd tennis-drills
python3 -m http.server 8765
```

Then open `http://localhost:8765`.
