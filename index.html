Weekly plan (2–3 machine days)

How this works

  • Only 2 or 3 Slinger sessions per week — not every day
  • Each session is ~200–250 balls (refill the 60-ball hopper 3–4 times)
  • Plan for 45–60 minutes — collect balls between hopper loads
  • Session 1 always prioritizes finishing points (your main habit fix)
  • Other days = rest or match play; still use the short-ball rule
  • Suggested days are flexible — tap a session whenever you get court time

Install on your phone

Add Court Focus to your home screen so it opens like an app at the court — no App Store needed.

  • iPhone: Safari → Share button → Add to Home Screen
  • Android: Chrome → menu (⋮) → Install app / Add to Home screen

Open via a web address first (not a downloaded file), then install.
